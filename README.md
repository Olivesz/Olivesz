**[custos-code](https://github.com/Olivesz/custos-code)** — checks a coding agent's final report against the log of what it actually did. Each claim comes back confirmed, contradicted or unwitnessed, and contradictions go back to the agent before it is allowed to stop.

**[kronos-quant](https://github.com/Olivesz/kronos-quant)** — a quantitative research platform with every estimator written on numpy. No estimator is trusted until it passes a gate whose answer is already known; the gates run in CI.

**[emergence](https://github.com/Olivesz/emergence)** — cellular automata in one engine, ending in a working CPU built from a single Wireworld rule: NAND gates and D flip-flops composed into processors that run Fibonacci, primes and a bubble sort.

**[ai-capabilities](https://github.com/Olivesz/ai-capabilities)** — social-deduction games played by language models, as a probe of reasoning under hidden information.

**[freeflow](https://github.com/Olivesz/freeflow)** · **[inf-mem](https://github.com/Olivesz/inf-mem)** — on-device speech-to-text that commits only the prefix two hypotheses agree on; a memory layer that persists across assistants.
